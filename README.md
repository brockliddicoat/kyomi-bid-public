# Kyomi Mouse Design Bid

The design bid for the Kyomi ultralight wireless gaming mouse, published with GitHub Pages at
https://brockliddicoat.github.io/kyomi-bid-public/

- `index.html` is the whole bid: one self-contained page.
- The page asks search engines not to index it, but anyone with the link can open it.
- It is built from the editable copy of the bid. Make changes there, then replace `index.html` here
  with the new build. Editing this file by hand works, but those changes are lost at the next build.
- To preview another accent color scheme without changing anything, add `?accent=primary`, `?accent=blues`,
  `?accent=purples` or `?accent=greens` to the address. The scheme the page opens in is chosen in the editable copy.
